## 8.2 Firewalls and security systems
Next generation firewall (NGFW): both filters packets and uses other technologies to detect and block a network attack, can be hardware or software
Stateless firewall/packet filter: allows or blocks a packet based on information in the packet header (source and destination IP addresses, port numbers, protocol type) using an:
Access control list (ACL): list of rules used by a firewall to control network traffic
- blocks all TCP and ICMP packets
- does not block traffic flows
Stateful firewall/dynamic packet filter: monitors and tracks active network connection sessions and blocks packets that do not belong to an active session
Host-based firewall: software firewall that runs on a host and controls inbound and outbound network traffic
Intrusion detection system (IDS): device or software application that detects malicious activity or a security policy violation
- Network intrusion detection system (NIDS): detects threats to networks
- Host-based intrusion detection system (HIDS): detects threats to the host
Network intrusion prevention system (NIPS): blocks threats to networks
NIDS/NIPS modes:
- Inline/in-band: 
	- network traffic is passed through
	- deployed at a network edge
	- can block an attack
- Passive/out-of-band: 
	- accessing through a dedicated path separate from primary traffic
	- receives a copy of network traffic
	- connected to monitoring port like a SPAN or TAP
	- cannot block a network attack

## 8.3 Authentication and authorization
Authentication, authorization, accounting {and auditing} (AAA{A}): framework used to control and track network access
- Authentication: identifies users by credentials, proves claim to an identity
- Authorization: enforces network resource policies, like allowing certain users to only access certain devices
- Accounting: monitors and captures user network access events {Auditing: user account misuse, hacking, configuration errors}
Identity and access management (IAM)/Identity management (IdM): framework of technologies and policies for managing user identities and controlling resource access
Identification: act of user (not always a person) claiming an identity by means of:
- Username
- Certificate: digital credential that binds user to a cryptographic key
- Token: physical device that can generate a unique code
- SSH key: cryptographic key-pair generated by terminal or SSH client
- Smart card: embedded microchip
Authentication factors: evidence of a user's identity
Authentication protocol: securely transfers authentication information between two parties
Subject: entity that wants a system resource (object)
Access control model: set of rules for controlling subject's access to object
Separation of duties (SoD): division of labor ensuring that no single person can jeopardize data integrity

## 8.4 Multifactor and policies
Single sign-on (SSO): log in to multiple systems with a single identity
Multi-factor authentication (MFA): login process with multiple verification factors
Authentication factor: evidence to prove claim to identity
- Knowledge: something they know
- Possession
- Inherence: physical characteristic
- Location
- Behavior
Knowledge-based authentication (KBA): requires knowledge of user's personal information
- Static KBA/shared secrets/shared secret questions: pre-agreed set of questions
- Dynamic KBA: knowledge questions that are not known beforehand
Account policy: how an account should be created, used, maintained, disabled, and removed

## 8.5 Types of authentication
Kerberos: authentication protocol that uses tickets and uses UDP port 88
Kerberos realm: network that uses Kerberos, involves three entities:
- Server
- Client
- Key Distribution Center (KDC): third party that authenticates and enables a user to access a service hosted on a server
	- Authentication server (AC): authenticates user
	- Ticket-granting server (TGS): issues a ticket a user can use to access a service if a TGT and service ID are provided
Kerberos authentication:
- Ticket-granting ticket (TGT): ticket that enables a user to request access to a service from a TGS
- Service ticket (ST): given by TGS; encrypted message with proof the user is authorized

Remote authentication dial-in user service (RADIUS): networking protocol for AAA services
- uses UDP port 1812 for authentication and authorization and UDP port 1813 for accounting
- only encrypts user's password
- combines authentication and authorization services
- Access-request: request that contains the user's credentials
- Access-reject: sent if credentials are invalid
- Access-challenge: sent if server needs additional information from user
- Access-accept: sent if credentials are valid
Network access server (NAS)/remote access server (RAS): access gateway between an untrusted external network and a trusted internal network

Terminal access controller access-control system plus (TACACS+): protocol developed by CISCO for centralized AAA services
- Encrypts the entire contents of each AAA packet
- TCP port 89
- commonly used for authenticating an administrator account to a network device
- supports multifactor authentication

## 8.6 Security attacks
Denial-of-service (DoS) attack: aims to prevent, disrupt, or delay authorized users from accessing a network resource
Distributed denial-of-service (DDoS) attack: simultaneously launched from multiple systems
- Network-based/volume-based: exhaust target system's network bandwidth
- Protocol-based/state exhaustion: exhaust network resources or infrastructure equipment
- Application-layer: exhaust specific functions or features of a program
Operational technology: hardware and software that monitors and controls industrial equipment
Domain hijacking: changing registration information of a domain without knowledge of consent of owner
URL redirection: using a URL to redirect a user to a malicious website; modifying host file
DNS cache poisoning/spoofing: redirects user to malicious website by modifying DNS query
Replay attack: an attacker eavesdrops on a secure network communication, intercepts a specific packet, and then delays or resends it later.

Data link layer attacks:
Address resolution protocol (ARP) cache poisoning/spoofing: attacker sends spoofed ARP messages on a LAN to associate the attacker's MAC address with the IP address of a target host on the LAN
Media access control (MAC) flooding: large number of invalid MAC addresses are sent to a network switch to overwrite the switch's MAC table; when the switch receives a packet without a valid MAC address on the table, it performs unicast flooding
- MAC table: maps each device's MAC address to a physical port on the switch
- Unicast flooding: broadcast of a packet to all ports on the switch
MAC cloning: changing the factory-assigned MAC address of a network device to bypass authentication

Man-in-the-middle (MitM) attack: attacker eavesdrops or modifies the communication between two parties; layer 3
Secure channel: communication channel that guarantees data authenticity and confidentiality
Man-in-the-browser (MitB) attack: uses malware to intercept or modify messages between a web browser and server; layer 7

Dynamic host configuration protocol (DHCP): used for automating the assignment of IP addresses and network configuration parameters to devices on an IP network
DHCP snooping: layer 2 control for preventing an unauthorized DHCP server from offering network configuration parameters
DHCP snooping attack: configures a rogue DHCP server to send a forged response to a request; MitM attack
DHCP starvation attack: aims to deplete a DHCP server's IP address pool; DoS attack
Internet protocol (IP) spoofing: changing source IP address of IP packets to impersonate another device

## 8.7 Endpoint security measures
Computer virus: malware that modifies the way a legitimate program operates
Full disk encryption (FDE): method to secure data drive; key is generated with an authentication token based on a user password or PIN
Self-encrypting drive (SED): HDD or SSD with encryption circuitry built into the drive; only hardware based
Opal: security specifications for SED published by Trusted Computing Group (TCG)
Endpoint hardening: improving security by reducing attack surface
Hotfix/quick-fix engineering (QFE) update: software update to address a specific problem
Service pack: collection of patches and hotfixes combined in a single package
Patch management: process of distributing and applying software updates
Zero-day vulnerability: unpatched system or device vulnerability, unknown to developers, but known to attackers
Zero-day exploit: attacks a zero-day vulnerability
Registry: hierarchical database that stores configuration settings in Windows

## 8.8 Other security measures
Group policy: operating system feature that controls the working environment of network objects in the Active Directory (AD)
- Group policy object (GPO): collections of settings used to manage and configure operating systems and applications
- Group policy template (GTO): contains policy settings or GPOs
Content filtering/URL filtering: device or software designed to stop unwanted access to unwanted websites
Open port: TCP or UDP port configured to accept data packets
Closed port: configured to reject or ignore data packets
Port enumeration: identifying a host's open ports and determining the services that use those ports
Operating system port: 16-bit unsigned number that identifies a host and network service
Well-known port: port number between 0 and 1023 reserved for commonly used services, assigned by IANA
Registered port: Between 1024 and 49151, for a specific use
Dynamic port: Between 49152 and 65535, can be used by any application
Security information management (SIM): practice of collecting, monitoring, and analyzing security-related data from computer logs and other sources
Security event management (SEM): identifying, collecting, monitoring, reporting security-related events in IT
Security information and event management (SIEM): combines SIM and SEM
User and entity behavior analytics (UEBA): uses algorithms and machine learning to detect anomalies
Security orchestration, automation, and response (SOAR) technology: helps coordinate, execute, and automate tasks in a single platform

### 8.9 VPN and remote access
Virtual networking computing (VNC): remote access protocol that uses a Remote Frame Buffer (RFB) protocol to control a remote computer, shares graphical desktop
Other remote access protocols:
- Serial Line Internet Protocol (SLIP)
- Point-to-Point Protocol (PPP)
- Point-to-Point Tunneling Protocol (PPTP)
- Remote Access Services (RAS): connects to a private network from a remote location
- Remote Desktop Protocol (RDP): optimized for Windows; shows graphical primitives only
Site-to-site/router-to-router VPN: private connection between two devices from the same organization
Client-to-site/remote access VPN: private connection between client and remote
Clientless VPN: creates remote access VPN tunnel using a web browser
VPN protocols:
Application/Transport Layer: SSL/TLS and HTML5
Network Layer: Internet Protocol Security (IPSec)
Data Link Layer: Layer 2 Tunneling Protocol (L2TP)
Zero trust: security framework that enforces continuous authentication, authorization, and security configuration validation for all users and devices
Least privilege: when a user is given the minimum levels of access to accomplish a task
