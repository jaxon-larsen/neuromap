## 10.1 DNS
Domain name system (DNS): hierarchical, distributed naming system containing information elements for network resources; translates domain names into IP addresses
Domain namespace: hierarchy of DNS administrative domains throughout the world
DNS zone: segment of the domain namespace assigned to an entity
DNS over TLS (DoT): sends TLS protocol encrypted queries attached to the UDP protocol
DNS over HTTPS (DoH): sends encrypted queries or requests by HTTP or HTTP/2 protocols
#### URL structure
Root domain: highest internet hierarchical level; often unshown dot at the end; drive.google.com.
Uniform resource locator (URL): also known as web address, specifies the location of an internet's web reference; **https:// drive.google.com**
Hostname is a domain name with at least one associated IP address
Fully qualified domain name (FQDN) is a domain name specifying the exact location in the DNS tree hierarchy; **drive.google.com**
Top-level domain (TLD) is the domain name's right-most label; drive.google.**com**
Second-level domain (SLD) is the subdomain TLD left label; drive.**google**.com
Subdomain is an additional domain's hostname; **drive**.google.com

 DNS resource record (RR) is a unit of information entry in DNS zone files
## 10.2 DNS process
 DNS recursor: receives queries from a client and starts the process to resolve the domain name to an IP address
 Root name server: DNS nameserver that operates in the root zone
 Top-level domain (TLD) name server: maintains information about the domain names sharing a common extension
 Authoritative name server: answers DNS questions about names in a DNS zone
DNS caching: local temporary database containing lookup information of recently visited websites

A DNS query is the request of DNS information from a DNS client to a DNS server
- Recursive query: one DNS server communicates with several other DNS servers to resolve the domain name to the IP address
- Iterative query: client communicates directly with each DNS server involved in the lookup.
- Non-recursive query: the DNS Resolver already knows DNS information from cache or a DNS Name Server query, which is the authoritative server for the domain
Reverse DNS lookup: querying technique connecting the domain name with an IP address
## 10.4 DHCP server & queries
DHCP messages:
- DHCP discovery: message broadcasted by client to discover any servers on a network
- DHCP offer: sent by server to offer a client a DHCP scope
- DHCP request: sent by client to accept a DHCP offer
- DHCP ack: sent by a server to acknowledge a DHCP request; assigns an IP address, a subnet mask, and default gateway lease to client
A UDP helper address: router configuration used to forward specified network traffic from one subnet to another
A DHCP relay agent: any node configured to forward DHCP messages between different subnets
Stateless address autoconfiguration (SLAAC): process allowing each network device to autoconfigure a unique IPv6 address without a centralized device maintaining IPv6 configurations
- creates a device's link-local address using a method known as EUI-64
	1. Determine the device's 48-bit MAC address. Ex:00:12:7F:EB:6B:40
	2. Insert FFFE in the MAC address to increase the bit size from 48 bits to 64 bits. Ex: 00:12:7F:FF:FE:EB:6B:40
	3. Invert the seventh bit, known as the universal/local (U/L) bit. Ex: 00 = 0000 0000 to 02 = 0000 0010
	4. Produce a link-local address. Ex: FE80::212:7FFF:FEEB:6B40
- Duplicate address detection (DAD): checks for uniqueness of an IPv6 address on a network
## 10.5 Network time protocol (NTP)
NTP server communication uses UDP port 123 and NTP clients use UDP port 1023
NTP timestamp: 64-bit binary fixed-point NTP number using a 32-bit part for seconds and a 32-bit part for fractional seconds
Precision time protocol (PTP): network protocol used to synchronize time at a nanosecond- or picosecond-level
Network time security (NTS): standard used to secure NTP using TLS
 Time server: device connected to a network that provides accurate time to clients using UDP protocol
 Stratum: level of NTP hierarchy and represents the distance to a reference clock
 Stratum 0: connected directly to atomic clock or GPS satellite
 Stratum 1: connected to stratum 0 device
