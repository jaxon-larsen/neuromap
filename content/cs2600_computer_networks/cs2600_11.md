## 11.1 Data center
Enterprise data center: used to process internal data and host mission-critical applications for a single organization
Colocation data center/carrier hotel: off-premises, leasable data center where an organization deploys its computing resources and associated equipment
Managed data center: organization uses a third party to oversee a leased facility
Cloud data center: off-premises, internet-accessible data center that a cloud service provider uses to offer subscription-based services
Edge data center: smaller, located close to an end user to reduce latency
Data center interconnect (DCI): links data centers in different locations to share resources
East-west traffic flow: flow between devices within a data center
North-south traffic: traffic flowing in an out of a data center (south: in, north: out)
Data center infrastructure management (DCIM): combines IT and data center facility management to optimize performance
Three-tier: less expensive
Leaf and spine: more expensive

## 11.2 Virtual
Hypervisor/virtual machine monitor (VMM): software or firmware used to virtualize a host machine's hardware platform
Host machine: used by a hypervisor to create a guest machine
Guest machine: VM running on a host machine
Virtual Network Computing (VNC): cross-platform screen sharing platform used to remotely control another computer
Network functions virtualization (NFV): replacement of network appliance hardware with virtual machines that use a hypervisor
Virtual switch (vSwitch): program that enables VMs to communicate with others
Virtual network interface card (vNIC): configuration of a VM connected to a network; has a MAC address
Virtual IP (VIP or VIPA) address: IP address that is shared by both members of a high availability server pool on the same subnet and does not correspond to a physical network interface
Type 1 hypervisor/native/bare metal: runs directly on a host machine
Type 2 hypervisor/hosted hypervisor: runs as an application on an existing operating system
VM escape: virtualization exploit where a process escapes a guest machine's logical isolation to interact with a host machine
VM sprawl/virtualization sprawl: virtualization exploit where an attacker creates a VM amount that consumes available resources
VM lifecycle management: series of procedures where a VM is created, maintained, monitored, and decommissioned when no longer needed

## 11.3 Cloud
Public cloud: cloud deployment model that is provisioned for use by the general public
Private cloud: cloud deployment model that is provisioned for exclusive use by a single organization
Virtual private cloud (VPC): private cloud where the cloud infrastructure resides within a public cloud.
Hybrid cloud: cloud deployment model that is where private and public clouds are bound together by standardized or proprietary technologies
Community cloud: cloud deployment model that is provisioned for exclusive use by organizations with common computing concerns
Infrastructure as code (IaC): method of managing and provisioning computer data centers through machine-readable definition files instead of hardware configuration or interactive configuration tools; does not provide increased security
Desired state: IaC feature that declares an infrastructure's final or desired state
Overlay network: virtual network abstraction layer built on top of an existing physical network infrastructure
Declarative IaC: set of parameters instructing the software on how the system needs to be configured once the process is finished
Procedural IaC: set of operations on how the system reaches the correct configuration
Overlay network: virtual network abstraction layer built on top of an existing physical network infrastructure
Cloud connection types:
- Point of presence (PoP): artificial demarcation point connecting communicating entities
- Private service connect: allows a private direct circuit across VPC networks belonging to different organizations
- Leased line: telecommunications service delivering high-speed internet access using a customer-specific leased connection
- Virtual private network (VPN): enables a private connection between two or more devices across a public network

## 11.4 Virtualization and networking
 Overlay network: virtual network abstraction layer built on top of an existing physical network infrastructure
 Software-defined networking (SDN): overlay network technology that centralizes a network's management and control planes
 Software-defined wide area network (SD-WAN): software-defined network centralizing a multi-location network's management and control planes.
 Secure access service edge (SASE): convergence of WANs or SD-WANs and network security services into a single cloud service model
 Software-defined visibility (SDV): refers to technologies enabling network traffic visibility to any monitoring device regardless of the device's physical location on a network

## 11.5 Network storage
Network-attached storage (NAS): file storage device connected to a network that allows multiple users and devices to access and share data through a centralized location
Storage area network (SAN): high-speed network providing access to network storage devices
Fibre channel (FC): is a high-speed data transfer technology that connects computers, servers, and storage devices; does not use OSI model
Fibre channel over ethernet (FCoE): storage networking technology allowing FC traffic to transmit over Ethernet networks
Internet small computing system interface (iSCSI): used to link data storage devices over a network and facilitate data transfers; client that originates the session is called an initiator
InfiniBand: high-speed networking technology primarily used for interconnecting servers and storage devices in high-performance computing (HPC) environments, data centers, and enterprise applications

 Internet Storage Name Service (iSNS): primarily used in SANs; technology that facilitates the discovery, management, and configuration of a TCP/IP storage network iSCSI device
