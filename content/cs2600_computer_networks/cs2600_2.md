### OSI Model
1. Physical - **Bits**
	- payload transmitted
	- cables (UTP, fiber)
	- signal transmission
2. Data link - **Frames**
	- bridge and switch
	- MAC added to PDV
	- receives transmission
	- adds header and trailer
3. Network - **Packets**
	- IP provides internetworking
	- segment logical header addressing
4. Transport - **Segments**
	- UDP or TCP provides delivery, divided into blocks
	- flow control
	- firewall
	- proxy server
	- load balancing
	- voice over IP (VoIP)
	- intrusion detection system (IDS)
5. Session
	- manages the dialogue between computers
	- starts, maintains, and ends each session
6. Presentation
	- syntax and format of data
	- translation, compression, encryption/decryption
7. Application - **Data**
	- SMTP, HTTP
	- file transfers

### DoD Model
1. Network Access
2. Internet
3. Transport
4. Application

Protocol Data Unit (PDU): data that is encapsulated
Port Number: identifies network application or service on a host
TCP header: contains connection and payload delivery details
MAC address: burned into hardware
Address resolution protocol (ARP): protocol that works with layers 2 and 3 to find the MAC address associated with a specific IP address
