Classless addressing or Classless Inter-Domain Routing: addressing scheme using variable length subnet mask (VLSM)
VLSM: subnet design using multiple masks on the same network
Default gateway: first usable host address (ex. 192.168.0.1)
Broadcast address: last host IP address in the range defined by the network or subnet
Network ID: first host IP address
Subinterface: Logical network interface created from a physical network interface
VLANs create a limited broadcast domain on a switched network

The IP range for the network 192.168.0.1/24 is 192.168.0.0 through 192.168.0.255.
The network ID 192.168.0.0 is the first available IP address; 192.168.0.1 is the first available IP host address.
192.168.0.255 is the broadcast address.

Find number of host addresses: $H = 2^{(32-n)} - 2$
Total bits: 32
Host bits: total bits - /x = exponent
Total IP addresses (total subnets): 2^exponent
Usable host addresses: total IP addresses - 2 (network and broadcast addresses)
