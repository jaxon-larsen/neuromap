## 12.2 Performance monitoring
Cyclic redundancy check (CRC) error: interface error occurring when a receiver calculates a different CRC value than the CRC value included in a sender's frame; faulty network media
Runt: frame size of less than 64 bytes; caused by collisions originating from a faulty NIC
Giant: frame exceeding a network or interface MTU configuration; caused by two networks with different configurations
Encapsulation error: missing layer 2 or 3 information

## 12.3 Performance monitoring resources
 Network baseline: parameter set describing network performance at the time of use
 Simple network management protocol (SNMP): network protocol for monitoring and managing networked devices in an IP network
- Managed device/network element: network node that implements an SNMP interface that allows access to the network node's information
- SNMP manager: monitors and controls a network element's activities using SNMP
- SNMP agent: software that runs on a network element and collects and maintains information on the network element
- SNMP trap: alert message sent from an SNMP agent to an SNMP manager to notify it of an event at a network element
- Management information base (MIB): hierarchically organized collection of SNMP managed devices and their associated properties
- Object identifier (OID): unique SNMP identifier for a managed device

## 12.4 Command-line performance monitoring
- A packet inter-network groper (ping) command, or ping, is a command-line tool used to verify source-to-destination, or end-to-end, connectivity between nodes using ICMP messages.
- A traceroute command, or traceroute, is a non-Windows command-line tool used to verify router-to-router, or hop-to-hop, connectivity between nodes using ICMP messages.
- A tracert command, or tracert, is a Windows command-line tool used to verify router-to-router, or hop-to-hop, connectivity between nodes using ICMP messages.
- A netstat command, or netstat, is a performance-gathering, command-line tool used to show network connection status and protocol statistics.
- An arp command is a protocol-specific tool executed from a command line to confirm IP-to-MAC address resolution via ARP.
- A hostname command is a protocol-specific tool executed from a command line to display a local device's hostname.
- A name server lookup (nslookup) command, or nslookup, is a deprecated protocol-specific tool executed from a command line to confirm DNS functionality.
- A domain information groper (dig) command, or dig, is a protocol-specific tool executed from a command line to confirm DNS functionality.

## 12.5 Performance monitoring software
- A bandwidth speed tester is command-line software used to measure and, in some cases, tune network performance. Ex: iperf.
- A port scanner is command-line software that shows the port status for a single node or an entire network. Ex: network mapper (nmap).
- A packet capture is the process of collecting network packets for further analysis and potential action. Ex: TCPdump.
- A protocol analyzer is packet capture software with a built-in ability to classify and analyze network packets.
- An IP scanner is network scanning software used to identify nodes by IP address.

## 12.6 Network platform performance monitoring
- A show interfaces command, or show interfaces, displays interface statistics for all of a device's interfaces.
- A show config command, or show config, displays a device's current configuration, known as a running configuration.
- A show route command, or show route, displays a device's local routing table.

## 12.9 High availability
- Resilience is a computing infrastructure's ability to remain functional during a service degradation or disruption.
- Redundancy is the duplication of a business resource to eliminate a SPOF.
- Diversity is the use of different technologies, vendors, cryptographies, and other controls to eliminate a SPOF.
- Scalability is the measure of a system's ability to handle increased demands.
- An active device is a device actively providing a service or function.
- A passive device is a dormant device providing only a service or function when an active device fails.
- A power supply unit (PSU), or power supply, is hardware used to convert and supply received electrical power to other computing hardware.
- Dual PSU, or dual supply, is a pair of PSUs used to ensure the failure of one PSU does not cause an outage or service disruption.
- A power distribution unit (PDU) is an electrical power strip capable of distributing received electrical power to multiple devices and PSUs.
- A managed power distribution unit (PDU) is a PDU with additional features such as remote electrical power monitoring and configuration.
- An uninterruptible power supply (UPS) is a PDU with a battery backup.
HA for network resources includes multipath and path diversity configurations. Path diversity, or path diversification, is a multipath configuration used to select the most optimal path for data flow reliability. Multipath and path diversification typically rely on network resources with multiple network adapters. 
NIC bonding, or NIC teaming, is a configuration combining, or aggregating, multiple physical NICs into a logical NIC.

Routers provide default gateway HA by using a first hop redundancy protocol (FHRP). First hop redundancy protocol (FHRP) is a protocol used to increase a default gateway's availability by aggregating multiple routers into a single virtual router. Two FHRP types exist:
- Virtual router redundancy protocol (VRRP) is a non-proprietary FHRP type available for various routers.
- Hot standby router protocol (HSRP) is a Cisco-proprietary FHRP type available for Cisco routers.

## 12.10 Replication and recovery
- Non-persistent storage is a temporary storage location where stored data does not survive a power loss.
- Persistent storage is a permanent storage location where stored data survives a power loss.
A device has multiple configurations depending on which storage location is used:
- A startup configuration is a device configuration located in persistent storage.
- A running configuration is a device configuration located in non-persistent storage.

Redundant array of inexpensive disks (RAID) levels:

| Level | Name                        | Minimum disks required | Description                                                   |
| ----- | --------------------------- | ---------------------- | ------------------------------------------------------------- |
| 0     | Striping                    | 2                      | Data is spread, or striped, to other drive(s) (No redundancy) |
| 1     | Mirroring                   | 2                      | Data is replicated, or mirrored, to other drive(s)            |
| 5     | Striping with parity        | 3                      | Striping with one drive providing error detection, or parity  |
| 6     | Striping with double parity | 4                      | RAID 5 with two parity drives                                 |
| 10    | Mirroring and striping      | 4                      | Combination of RAID 1 and 0                                   |
- A cold site is an empty facility where an organization can transport business continuity resources to.
- A warm site is a facility where an organization has some, but not all, business continuity resources.
- A hot site is a facility where an organization has all business continuity resources.
- A cloud site is the use of a cloud service provider's resources as a DR site.
