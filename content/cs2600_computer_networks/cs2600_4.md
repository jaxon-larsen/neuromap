Physical/Media access control address (MAC address): 48-bit number burned in network interface controller, created by concatenating the Organizationally Unique Identifier (OUI) and Device ID
Logical/Internet protocol (IP address): 32 (IPv4) or 128-bit (IPv6) number assigned to a network interface controller 
Port number: 16-bit unsigned number that uniquely identifies a network application or service on a host
### IPv4
32-bit numeric address divided into four 8-bit octets
Subnet mask: 32-bit number used to divide an IP address into a host and network portion
- /x is used to refer to the number of 1s in the front of its binary form

### IPv6
Network component: first 64 bits
- Prefix length: first 48 bits
- Subnet ID: last 16 bits
Node component: last 64 bits

Three rules for displaying IPv6 addresses exist:
1. Leading zeros are removed within each hexadecimal group.
2. Two or more hexadecimal groups containing all zeros are replaced with :: (Rule 2 can only be executed once per each IPv6 address).
3. A hexadecimal group containing all zeros is replaced with a single zero.

### Port Numbers
Range	Name	Description
0 – 1023	Well-Known Ports	Reserved for core services like HTTP (80), HTTPS (443), and SSH (22).
1024 – 49151	Registered Ports	Assigned by IANA for specific applications or vendor-specific services.
49152 – 65535	Dynamic/Private Ports	Temporary ports used by client applications during a connection.

| **Port**    | **Protocol** | **Service Name**                   | **Purpose**                                                                   |
| ----------- | ------------ | ---------------------------------- | ----------------------------------------------------------------------------- |
| **20/21**   | **FTP**      | File Transfer Protocol             | Port 20 (Data) and 21 (Control) for transferring files between systems.       |
| **22**      | **SSH**      | Secure Shell                       | Secure remote login and command execution.                                    |
| **23**      | **Telnet**   | Telnet                             | Unsecure remote login (transmits data in plain text).                         |
| **25**      | **SMTP**     | Simple Mail Transfer Protocol      | Routing and transferring email between mail servers.                          |
| **53**      | **DNS**      | Domain Name System                 | Resolving domain names to IP addresses.                                       |
| **80**      | **HTTP**     | Hypertext Transfer Protocol        | Delivering unencrypted web pages.                                             |
| **110**     | **POP3**     | Post Office Protocol v3            | Retrieving email from a server (downloads and typically deletes from server). |
| **143**     | **IMAP**     | Internet Message Access Protocol   | Retrieving email from a server (syncs across devices, stays on server).       |
| **161/162** | **SNMP**     | Simple Network Management Protocol | Monitoring and managing network devices.                                      |
| **443**     | **HTTPS**    | HTTP Secure                        | Delivering web pages over an encrypted (SSL/TLS) connection.                  |
| **445**     | **SMB**      | Server Message Block               | File and printer sharing in Windows environments.                             |
| **587**     | **SMTP**     | SMTP (Submission)                  | Modern port for client-to-server email submission using encryption.           |
| **993**     | **IMAPS**    | IMAP over SSL                      | Securely syncing email across devices.                                        |
| **995**     | **POP3S**    | POP3 over SSL                      | Securely retrieving email from a server.                                      |
| **3389**    | **RDP**      | Remote Desktop Protocol            | Windows-specific remote desktop connections.                                  |
