### IGP and convergence
Autonomous system (AS): large network or collection of networks that has a unified routing policy
Interior gateway protocol (IGP): type of routing protocol used for exchanging routing table information within an AS; types include distance vector, link state, and advanced distance vector protocols
Convergence: when all AS participating routers have the same topological information

### Distance Vector Protocol
Distance vector protocol: routing protocol that uses distance vectors or hop count as a primary metric to determine a packet's destination route
Routing information protocol (RIP): distance vector protocol that uses hop count as the main counting metric; maximum routes included in a single broadcast bracket is 25
Interior Gateway Routing Protocol (IGRP): proprietary distance vector routing protocol used to send routing information within an autonomous system

## 6.3: Link state, BGP and EIGRP protocols
### OSPF
Open shortest path first (OSPF): 
- IP routing protocol used to send routing information over a single AS 
- Needs every router to have a complete map of network topology
- Uses SPF/Dijkstra's algorithm
- Transport layer using IP protocol 89

### BGP
Border gateway protocol (BGP): enables the internet to exchange routing information between autonomous systems; application layer using TCP port 179

### Hybrid
Enhanced Interior Gateway Routing Protocol (EIGRP): a distance vector routing protocol used to send routing information within an AS; uses IP protocol 88; better than IGRP

## 6.4 Common protocols
- Management protocol: defines the policies to monitor, manage, and maintain the network
- Communication protocol: defines the data communication's format and rules
- Security protocol defines how to secure data transmissions

Server message block (SMB) protocol: client-server communication protocol used for sharing access to files, printers, and serial ports
Network management protocol (NMP): suite of protocols defining processes, procedures, and policies to manage a network
Internet control message protocol (ICMP): protocol used by network devices to communicate problems with data transmission; network layer
Simple network management protocol (SNMP): monitors and manages networked devices on an IP network; application layer; TCP port 161 (agents) and 162 (traps)
Address resolution protocol (ARP): network protocol for mapping dynamic IP addresses to the physical device address (MAC address)

Internet protocol security (IPSec): protocol suite for securing data communications over an IP network; uses authentication header (AH) and encapsulating security protocol (ESP)
Simple Mail Transfer Protocol (SMTP): network protocol for sending, receiving, and relaying outgoing emails

HTTP is unencrypted, HTTPS is encrypted with SSL or TLS

File transfer protocol: application that uses port 20 (data) and port 21 (control)
