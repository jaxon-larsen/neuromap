## 7.1 Network transmission
Cast: how packets are sent across the network media to the destination
Unicast: 1 device
Multicast: multiple devices
Broadcast: all devices
Broadcast domain: logical network segment that includes all devices that receive broadcast traffic on layer 2; switch ports are in the same domain, router ports are different
Collision domain: where packet collisions occur; each switch, bridge, or router port is a separate collision domain, but hubs are in the same
Bridge: Layer 2 device used to connect network segments together to form a single logical network
- Transparent
- Multiport
- Store and forward
Maximum transmission unit: largest PDU in a layer 3 transaction; maximum frame size of a medium minus the amount of overhead
Jumbo frame: Ethernet frame with a payload greater than the standard MTU of 1500 bytes
Carrier sense multiple access (CSMA): medium access control (MAC) protocol developed to decrease a network's collisions
- 802.11ac IEEE standard
- Collision detection: sends a jam signal when a collision is detected
- Collision avoidance: uses request to send (RTS) and clear to send (CTS) before transmission
## 7.2 Network traffic
Traffic/packet shaping: prioritizes network traffic based on importance
- Quality of service (QOS): prioritizes resource-intensive applications at layer 3
- Class of service (COS): prioritizes based on layer 2
### VPN Traffic Modes
Full tunnel:
- routes and encrypts all network traffic through the VPN
- more recommended and secure
- better for confidential data
Split tunnel:
- routes and encrypts all non-internet traffic
- can protect data without losing access to local network devices

Network loop/layer 2 loop/bridge loop: network topology where more than one path exists 
Broadcast/network storm: large number of broadcast and multicast packets on a network in a short time period
Broadcast storm prevention/storm control: preventing or reducing packet rebroadcasts on a LAN
Bridge protocol data unit (BPDU): packet exchanged between switches on a LAN to detect network loops
Spanning tree protocol (STP): network protocol a layer 2 device uses to eliminate a loop; IEEE 802.1D
Rapid spanning tree protocol (RSTP): faster than STP; IEEE 802.1w
## 7.3 Switch features
Switch port configurations:
- Speed
- Duplex
	- Half-duplex: packets flow in one direction
	- Full-duplex: packets flow simultaneously in both directions
- Flow control: monitoring data flow and temporarily halting Ethernet data transmission if a switch port buffer fills
- Port security: secures a network by preventing unknown devices from forwarding packets
	- only packets matching an allowed port MAC address are allowed through the port
	- limits the number of MAC addresses for a given switch port
	- port security can be implemented on a per-port basis
- Port aggregation
- Port mirroring/switched port analyzer (SPAN)/roving analysis port (RAP)
	- used to send a copy of network packets transmitted over one switch port to another
	- can mirror inbound and/or outbound traffic

Tagged/trunk port: switch port configured to carry traffic from multiple VLANs
- encapsulation method for VLAN tagging is usually 802.1Q (4 bytes), also known as Dot1q
Untagged/access port: switch port configured to carry traffic from a single VLAN
Native VLAN: unused VLAN used to receive all untagged frames from untagged ports

## 7.4 Switch configuration
Common switch configurations:
- Power over Ethernet (PoE): provides power and data to a device using bounded media

| IEEE standard                      | Maximum power rating | Device power available | Supported cable |
| ---------------------------------- | -------------------- | ---------------------- | --------------- |
| 802.3af Type 1 - PoE               | 15.4 W               | 12.95 W                | CAT3 and above  |
| 802.3at Type 2 - PoE+              | 30 W                 | 25.5 W                 | CAT5 and above  |
| 802.3bt Type 3 - 4PPoE/PoE++       | 60 W                 | 51 W                   | CAT5 and above  |
| 802.3bt Type 4 - 4PPoE/ PoE++/UPoE | 100 W                | 71 W                   | CAT5 and above  |
- Tagged ports
- VLAN tunneling
- Port duplex
- Port speed
- Auto medium dependent interface (MDI)/medium dependent interface crossover (MDI-X) port feature

Link aggregation: combines network connections in parallel to increase throughput and/or link redundancy
Logical aggregation group (LAG): a single logical channel created when using link aggregation for combining physical network connections
Link aggregation control protocol (LACP): specified by IEEE 802.3ad, provides negotiation method allowing switches to create and enable the configured aggregate link
- LACP system priorities: determine sequence of two end devices selecting active interfaces to join a link aggregation group
- LACP interface priorities: selects which Ethernet-trunk interfaces are active and assigns a priority
- LACP/M:N mode: M is the number of active links, N is the number of back-up links; guarantees reliability and allows load-balancing traffic
VLAN tunneling/802.1Q tunneling/Q-in-Q: used by service provider to segregate customer traffic through the addition of a second tag entry
Asymmetrical link: connects a switch trunk port to another switch's tunnel port

## 7.5 VLANs
VLAN database: file used to store VLAN-related information
VLAN types:
- Default VLAN: preconfigured VLAN type on all switch ports, allowing any connected device to communicate with other connected devices
- Data VLAN: carrying user-generated traffic, such as email or web browsing
- Voice VLAN: specifically tailored to support VoIP traffic
- Management VLAN: provides administrative access to a switch
Native VLAN: unused VLAN used to receive all untagged frames from untagged ports
VLAN membership types:
- Port-based VLAN/interface-based VLAN/static VLAN: host is connected to a specific switch port that is assigned to a VLAN; layer 1.
- MAC-based VLAN: host's MAC address is used to assign the host to a VLAN; layer 2
- Protocol-based VLAN: protocol types are used to assign a host to a VLAN; layer 3
Ways devices can be connected to VLAN:
- Trunk line: all devices aware
- Access link: connects unaware device to aware port
- Hybrid link: connects both aware and unaware

## 7.6 VLAN design and configuration
VLAN threats:
- VLAN hopping: attacker breaches a vulnerable VLAN and uses it to hop to others
- Switch spoofing: attacker imitates, or spoofs, a trunking switch
- Double-tagging: attacker tags a frame with an outer VLAN and an inner, or target, VLAN
VLAN switch configuration:
1. Enter configuration mode
2. Enter VLAN mode to create a VLAN or range of VLANs
3. Exit VLAN mode
4. Confirm VLAN/VLAN range creation
5. Save the VLAN configuration to the VLAN database
Switched virtual interface (SVI)/VLAN interface: layer 3 interface created on a switch to provide communication between each configured VLAN

## 7.7 Security zones and IP support
Security zone: network segment containing network resources with the same trust level
- Trusted/private zone: contains network resources only accessible to those authorized
- Untrusted/public zone: contains network resources outside an organization's control
- Demilitarized zone (DMZ)/screened subnet: between above; protects network resources from untrusted traffic
Honeypot: lures attackers to isolated, monitored, valuable resource for information-gathering
Network address translation (NAT): converts private IP address to public allowing internet access to a network device; OSI layer 3
Teredo: provides IPv6 tunneling when hosts are located behind IPv4 NATs
NAT64: translator between IPv4 and IPv6 hosts
Port address translation (PAT): allows multiple private network devices to connect to the internet using the same IP address
Static/one-to-one NAT: provides one-to-one translation of a local address to a public address; translations recorded in table until deleted
Dynamic NAT: translations show up when needed and are deleted after a timeout period
Source network address translation (SNAT): translates source IP to public IP
Dual stack: originate and understand both IPv4 and IPv6

## 7.8 Routers
| Specialized router type | Characteristic                                                                                             |
| ----------------------- | ---------------------------------------------------------------------------------------------------------- |
| Edge router             | Installed at the boundaries of a network. Distributes packets across multiple networks.                    |
| Core router             | Distributes packets within the same network rather than across multiple networks.                          |
| VPN router              | Is a normal router with VPN client software installed. Every VPN connected device is protected by the VPN. |
Router advertisement (RA): local network transmission announcing, or advertising, a router's IP address
RA guard: security feature to block rogue RA transmissions
Router access control list (ACL): set of rules controlling which packets can pass through the next hop or destination
- Standard ACL: controls based on the source IP address
- Extended ACL: controls based on the source and destination IP address, information, port, or protocol
