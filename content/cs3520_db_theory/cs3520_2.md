[[cs]] [[class]] [[databases]]

Relational rule: part of every relational model
- Unique primary key: values may not repeat
- Unique column names
- No duplicate rows (in all columns)

Business rule: specific to particular database

| Sublanguage                                                         | Acronym | Example statements                                                                           |
| ------------------------------------------------------------------- | ------- | -------------------------------------------------------------------------------------------- |
| Data Definition Language  <br>defines database structure.           | DDL     | CREATE TABLE City (<br>   ID INTEGER,<br>   Name VARCHAR(15),<br>   Population INTEGER<br>); |
| Data Query Language  <br>retrieves data.                            | DQL     | SELECT Name<br>FROM City<br>WHERE Population > 15000;                                        |
| Data Manipulation Language  <br>inserts, updates, and deletes data. | DML     | INSERT INTO City<br>VALUES (100, 'Geneva', 206000);                                          |
| Data Transaction Language  <br>manages transactions.                | DTL     | START TRANSACTION;<br><br>COMMIT;                                                            |
| Data Control Language  <br>specifies user access to data.           | DCL     | CREATE USER 'jordan';<br><br>GRANT ALL ON sakila.actor <br>TO 'jordan';                      |
