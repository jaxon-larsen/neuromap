We are given an [[Oracle]] that implements this function:
$f:\{0,1\}^n \rightarrow \{0,1\}$
Takes n-bit binary values as input and produces either a 0 or 1 as an output for each; it is either constant (all 0s or 1s on inputs) or balanced (half 0s and half 1s on inputs); using the oracle, is $f$ constant or balanced?

Specifically designed to be easy for a quantum algorithm and hard for any deterministic classical algorithm
