The phase in a program's life cycle when an attribute is associated, or "bound" to an entity.
### Key Binding Times in C / C++

| **Phase**                        | **Description**                                                                                         | **Example**                                                                                                                                                        |
| -------------------------------- | ------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Language-Definition Time**     | When the language specification/standard (e.g., ISO C++ Standard) is written.                           | The meaning of the `+` operator for integers; keyword meanings (`if`, `while`).                                                                                    |
| **Language-Implementation Time** | When compiler and library authors design the toolchain for a specific target architecture.              | The size and range of basic types (e.g., whether `int` is 16-bit or 32-bit; representation of floating-point numbers).                                             |
| **Compile Time**                 | When the compiler translates source code into machine/assembly code (object files).                     | Binding a variable name to its data type; binding an identifier to a relative stack offset; resolving static function calls and templates.                         |
| **Link Time**                    | When the linker merges separate object files and static libraries into an executable or shared library. | Resolving external function calls (e.g., matching a `printf()` call to its object symbol); resolving global variable definitions across compilation units.         |
| **Load Time**                    | When the operating system loader reads the executable into memory prior to execution.                   | Assigning base virtual memory addresses; dynamic linking of shared libraries (`.so` / `.dll`); applying ASLR offsets.                                              |
| **Runtime**                      | While the program is actively executing instructions.                                                   | Allocating local variables on the call stack; resolving dynamic memory allocation (`malloc`/`new`); resolving polymorphic virtual method calls (dynamic dispatch). |
